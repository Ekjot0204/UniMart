UNIMART - ROBUST MULTI-PAGE FRONT-END

1. Extract this ZIP anywhere.
2. Open index.html in Chrome.
3. The navigation changes the URL using ?page=... and renders a separate page view.
4. No CSS, JS, image, or other HTML files are required.
5. Login/signup, rental requests, and listings use browser localStorage.

? page=home
? page=browse
